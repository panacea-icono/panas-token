# Audio Processing Directory

Este directorio se utiliza para almacenar archivos de audio temporales durante el procesamiento.

Los archivos aquí son procesados por el servicio Whisper API para:
- Transcripción de voz a texto
- Detección de idioma
- Traducción automática

## Formatos soportados
- MP3
- WAV
- M4A
- FLAC
- OGG
